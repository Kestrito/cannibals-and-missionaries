# Cannibals & Missionaries

A Pygame version of the classic river-crossing game.




## Gameplay

Click (or press if playing on mobile) on a cannibal or missionary to put them on or take them off the raft, and click on the raft to make it sail to the other island. The raft can take up to two people, and need at least one to be able to sail. And if the cannibals are left on a side with a fewer non-zero number of missionaries, you **lose**. Win by taking all cannibals and missionaries to the right island.




## Requirements

To install the requirements, run the following line in cmd:

`python -m pip install -r requirements.txt`
